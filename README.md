# LEGO Data Analysis

This project explores the fascinating world of LEGO using real-world data. The analysis is built around a dataset from [Rebrickable](https://rebrickable.com/downloads/), which catalogs all LEGO sets and pieces ever released. It is designed to be both an educational project and a deep dive into LEGO's product history.

## 📊 Objectives

Through data analysis and visualization, this notebook addresses questions like:

- 🧱 What is the most enormous LEGO set ever created?
- 🏁 When did LEGO first begin, and what were the initial sets like?
- 🎭 Which LEGO theme has the most sets—original themes like *Ninjago* or licensed ones like *Harry Potter*?
- 📈 How did LEGO expand its product offering over the years?
- 🧩 Do LEGO sets tend to grow in size and complexity over time?

## 🧰 Technologies Used

- Python 3
- Jupyter Notebook
- Pandas

- Seaborn

## 📂 Dataset

The data is sourced from **Rebrickable**, which provides downloadable datasets covering all LEGO parts, sets, themes, and inventories.
